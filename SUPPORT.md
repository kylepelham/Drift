# Support

Drift is an open-source project maintained on a best-effort basis. There is no guaranteed
response time, but clear reports with reproducible details are much easier to help with.

## Start here

- Read the [README](README.md) for installation and development setup.
- Check the guides under [docs/](docs/) for engine, MCP, persistence, extension, and
  theming behavior.
- Search [existing issues](https://github.com/kylepelham/Drift/issues) for the same
  symptom before opening a new report.

## Choose the right channel

- Use the [bug report form](https://github.com/kylepelham/Drift/issues/new?template=bug_report.yml)
  for crashes, regressions, broken UI, and reproducible integration failures.
- Use the [feature request form](https://github.com/kylepelham/Drift/issues/new?template=feature_request.yml)
  for product improvements and new behavior.
- Use GitHub's [private report form](https://github.com/kylepelham/Drift/security/advisories/new)
  for security vulnerabilities. Never disclose a vulnerability in a public issue.

Include your Drift version, Windows version, reproduction steps, expected result, and
actual result. Remove credentials, private prompts, workspace source, and personal data
from screenshots and logs before attaching them.

Provider account access, quotas, billing, and model availability are controlled by the
provider and should be raised with that provider. Issues that reproduce in the OpenCode
CLI without Drift may belong in the [OpenCode repository](https://github.com/sst/opencode/issues).
