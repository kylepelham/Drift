Reads a file from the filesystem and returns its contents with line numbers (`N: text`). Read a file before changing it: edits copy their text from what `read` shows, and overwriting or deleting a file this session has not read is refused.

- Returns up to 2000 lines starting at `offset`; the tail of the output says how to read the rest.
- Long lines are cut at 2000 characters.
- Given a directory it lists the entries instead.
- Images (PNG, JPEG, GIF, WebP, up to 32 MB, scaled to 2000 pixels and 5 MB) and PDFs (up to 10 MB) come back for you to look at. Other binary files are refused. A text file over 10 MB (a log, generated output) is read a page at a time: give `offset` to go deeper; it does not say how many lines it has.
- Prefer one larger read to many small slices; to find a passage in a large file, `grep` for it.
- Read several files in one turn by issuing several calls at once.
