Fetches a URL and returns its content. HTML pages come back as Markdown by default; other content types are returned as-is.

- Use it for documentation, changelogs, issues and API references the task points at. It is not a search engine: you need the URL.
- Pages are cut at 100,000 characters; for a long page, fetch and then look for the part you need.
- Each new host is asked about once per session.
