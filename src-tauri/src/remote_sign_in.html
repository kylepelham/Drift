Use the username and password set in Drift on your computer.

Browser sign-in is not set up yet. On the computer running Drift, open Settings > Remote Access and set a password under Browser access.

About the warning on this address. The connection is encrypted with a certificate your computer made, which browsers do not know, so they warn the first time. Download the certificate and install it as a trusted certificate authority to stop the warning. First check that its SHA-256 fingerprint matches the one in Drift under Settings > Remote Access > Browser access. It can only vouch for private network addresses.
