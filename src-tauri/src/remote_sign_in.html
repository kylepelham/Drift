Connection security

The connection is encrypted with a certificate made by your computer. Browsers do not know that certificate, so they warn the first time you connect.

Download the certificate and install it on this device to stop the warning.

How to install it

Android: Settings > Security > Encryption & credentials > Install a certificate > CA certificate, then choose the downloaded file.

iPhone and iPad: open the downloaded profile in Settings > Profile Downloaded and install it. Then turn it on in Settings > General > About > Certificate Trust Settings.

Windows, macOS, Linux: import it as a trusted root certificate authority.

Before installing, check that its SHA-256 fingerprint matches the one in Drift under Settings > Remote Access. The certificate can only vouch for private network addresses.
